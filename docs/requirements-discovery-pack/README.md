# Requirements Discovery Pack

This pack is designed for a requirement-gathering session where the goal is to confirm needs, correct assumptions, and identify owners.

## How to use this pack

Send this pack to the client team 2-3 days before the meeting so they can pre-read and start filling in responses. Clinical stakeholders are busy and should not be expected to fill everything in live.

## Files to send

1. `requirements-discovery-session-guide.md` (for context on the session)
2. `01-current-understanding.csv`
3. `02-clinical-validation.csv`
4. `03-workflow-and-operations.csv`
5. `04-technical-integration-ai-hosting.csv`
6. `05-decisions-and-owners.csv`
7. `06-colposcopy-detailed-rule-review.csv` (optional clinical appendix)
8. `07-gynaecology-detailed-rule-review.csv` (optional clinical appendix)

## Recommended approach in the meeting

- Position the session as discovery, not sign-off.
- Tell them these sheets are prefilled from:
  - Jasveen's email
  - the colposcopy grading guide (scanned)
  - the current colposcopy grading template image
  - the gynaecology grading guideline PDF
- Ask them to correct, confirm, or mark unknowns.
- Ask them to nominate owners for:
  - colposcopy clinical validation
  - gynaecology clinical validation
  - workflow and operations
  - technical and integration decisions
- Ask about the boundary with the other vendor's work early in the session.

## Suggested status values

- `Confirmed`
- `Assumed`
- `Unknown`

## Suggested decision values

- `Accepted`
- `Accepted with changes`
- `Needs clarification`
- `Needs policy decision`
- `External dependency`
- `Out of scope for pilot`
