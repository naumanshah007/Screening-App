# Guideline-derived oracle

The stable, machine-readable oracle is `guideline-oracle.json`. It was independently transcribed from the clinical-pathway requirements in the supplied audit brief and corroborated against the repository's earlier source-image audit; it was not generated from engine outputs.

Critical limitation: the original June 2023 v1.1 PDF, Figures 1–10, Table 1, addenda, and immune-deficiency guidance are not available in this workspace/attachment set. Therefore this oracle covers only explicitly stated branches and labels every unavailable detail as unresolved. It must be reconciled against the original sources by a qualified NZ cervical-screening clinician before validation.

National routing is kept separate from local booking priority. Histology, biopsy, visible-lesion, MDM/MDT, suspected invasion, treatment selection, and local Healthcare Pathways branches are clinician-led unless the source explicitly supplies a deterministic action.
