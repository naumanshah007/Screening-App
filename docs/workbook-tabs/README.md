# Validation Workbook Tabs

These CSV files are intended to be opened in Excel or Google Sheets as separate tabs.

Suggested workbook order:

1. `01-current-understanding.csv`
2. `02-clinical-validation.csv`
3. `03-workflow-operations.csv`
4. `04-technical-integration-ai-hosting.csv`

Recommended status values:

- `Confirmed`
- `Assumed`
- `Unknown`

Recommended decision values:

- `Accepted`
- `Accepted with small changes`
- `Needs fix`
- `Needs policy clarification`
- `External dependency`
